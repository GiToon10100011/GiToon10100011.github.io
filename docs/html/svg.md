# SVG

SVG는 벡터 그래픽을 표현하기 위한 표준 형식이다. 벡터 그래픽은 픽셀 기반의 비트맵 이미지와 달리, 수학적으로 정의된 형태를 사용하여 크기에 상관없이 높은 퀄리티를 유지할 수 있다.

SVG는 다음과 같은 형식으로 사용된다.

```html
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" />
</svg>
```

svg를 활용하여 이미지의 색상이나 path를 변경하여 재밌는 애니메이션을 만들 수도 있다.
