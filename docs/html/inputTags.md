# input 태그

input 태그는 사용자가 입력한 데이터를 서버로 전송하기 위해 사용되는 태그이다.
다양한 type속성 유형이 존재하는데, 지금부터 하나씩 알아보자.

1. `text` - 한줄 텍스트 입력 양식
2. `password` - 비밀번호 입력 양식
3. `number` - 숫자 입력 양식
4. `email` - 이메일 입력 양식
5. `tel` - 전화번호 입력 양식
6. `search` - 검색 입력 양식
7. `date` - 날짜 입력 양식
8. `time` - 시간 입력 양식
9. `datetime-local` - 날짜와 시간 입력 양식
10. `month` - 월 입력 양식
11. `week` - 주 입력 양식
12. `url` - URL 입력 양식
13. `color` - 색상 입력 양식
14. `checkbox` - 체크박스 입력 양식
15. `radio` - 라디오 버튼 입력 양식
16. `file` - 파일 입력 양식
17. `submit` - 전송 버튼 입력 양식
18. `reset` - 초기화 버튼 입력 양식
19. `button` - 버튼 입력 양식
20. `image` - 이미지 입력 양식
21. `file` - 파일 입력 양식
22. `hidden` - 숨겨진 입력 양식
