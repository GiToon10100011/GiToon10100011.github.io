# CSS

> 스타일 시트 언어로, 태그에 스타일을 부여하는 언어이다.

## 선택자

CSS에서는 특정 HTML 요소를 선택하여 스타일을 적용하는 방법이 있다. 이를 선택자라고 한다.
가장 많이 쓰이는 선택자들은 전체, 태그, 아이디, 클래스 선택자 등이 존재한다.
아래에서 좀 더 자세히 알아보자.

- 전체 선택자 - `*`를 사용한다. 전체 선택자는 모든 요소를 선택한다.

- 태그 선택자 - `태그이름`을 사용한다. 태그 선택자는 특정 태그를 선택한다.

- 클래스 선택자 - `.`을 사용한다. 클래스 선택자는 특정 클래스를 가진 요소를 선택한다.

- ID 선택자 - `#`을 사용한다. 아이디 선택자는 특정 id속성이 있는 요소를 선택한다. id속성은 웹 페이지 내부에서 중복되면 안된다는 규정이 있기에 특정 요소를 선택하는데 유용하다.

- 속성 선택자 - `태그[attribute]`와 같은 형식으로 사용된다.

```css
/* href 속성이 있는 <a> 요소 선택 */
a[href] {
  color: red;
}

/* type 속성이 text인 <input> 요소 선택 */
input[type="text"] {
  color: blue;
}
```

- 자식 선택자 - `>`를 사용한다. 자식 선택자는 특정 요소의 자식 요소를 선택한다. table태그에는 자손 선택자를 사용할 수 없으며, `table > tr > th`가 아닌, `table tr th{}` 와 같이 사용해야 한다. 이는 [HTML문서](/docs/2024-09-07-HTML.html#tabledesc)에서 언급했듯이 <span style="color: yellowgreen;">웹 브라우저에서 tbody, thead, tfoot 태그를 자동으로 추가</span>하기 때문이다.

- 자손 선택자 - ` `(공백)을 사용한다. 자손 선택자는 특정 요소의 자손 요소를 선택한다.<span style="color: crimson;"> >는 직계 자식을 선택하는 것이며, 자손 선택자는 모든 자손을 선택</span>한다.

- 인접 형제 선택자 - `+`를 사용한다. 인접 형제 선택자는 특정 요소의 인접 형제 요소를 선택한다.

- 일반 형제 선택자 - `~`를 사용한다. 일반 형제 선택자는 특정 요소의 일반 형제 요소를 선택한다. +는 바로 다음 형제를 선택하는 것이며, ~는 모든 형제를 선택한다.

- 부모 선택자 - `:has()`를 사용한다. 부모 선택자는 특정 요소의 부모 요소를 선택한다.

- 부정 선택자 - `:not()`를 사용한다. 부정 선택자는 특정 요소의 부정 요소를 선택한다.

- 반응 선택자 - `태그:반응`를 사용한다. `:active, :hover, :focus, :checked, :disabled` 등이 있다. 반응 선택자는 특정 요소의 반응 요소를 선택한다.

```css
/* 버튼에 호버 시 배경색이 변경 */
button:hover {
  background-color: red;
}
```

- 유일 자식 선택자 - `:only-child`를 사용한다. 유일 자식 선택자는 특정 요소의 유일 자식 요소를 선택한다.

```css
/* 부모 요소 안에 자식이 하나뿐인 <li> 요소 선택 */
li:only-child {
  color: red;
}
```

- 첫 번째 자식 선택자 - `:first-child`를 사용한다. 첫 번째 자식 선택자는 특정 요소의 첫 번째 자식 요소를 선택한다.

- 마지막 자식 선택자 - `:last-child`를 사용한다. 마지막 자식 선택자는 특정 요소의 마지막 자식 요소를 선택한다.

- 첫 번째 형식 구조 선택자 - `:first-of-type`를 사용한다. 첫 번째 형식 구조 선택자는 특정 요소의 첫 번째 형식 구조 요소를 선택한다. -child는 자식을 선택하는 것이며, -of-type은 형식 구조를 선택하는 것이다.

```css
/*첫번째 자식*/
div:first-child {
  color: red;
}

/* 첫 번째 <p> 요소 선택 */
p:first-of-type {
  color: red;
}
```

- 마지막 형식 구조 선택자 - `:last-of-type`를 사용한다. 마지막 형식 구조 선택자는 특정 요소의 마지막 형식 구조 요소를 선택한다.

- n번째 자식 선택자 - `:nth-child()`를 사용한다. n번째 자식 선택자는 특정 요소의 n번째 자식 요소를 선택한다.

- n번째 형식 구조 선택자 - `:nth-of-type()`를 사용한다. n번째 형식 구조 선택자는 특정 요소의 n번째 형식 구조 요소를 선택한다.

- n번째 뒤쪽에서 마지막 자식 선택자 - `:nth-last-child()`를 사용한다. n번째 뒤쪽에서 마지막 자식 선택자는 특정 요소의 n번째 뒤쪽에서 마지막 자식 요소를 선택한다.

- n번째 뒤쪽에서 마지막 형식 구조 선택자 - `:nth-last-of-type()`를 사용한다. n번째 뒤쪽에서 마지막 형식 구조 선택자는 특정 요소의 n번째 뒤쪽에서 마지막 형식 구조 요소를 선택한다.

이외의 선택자들도 존재하는데, <a href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Selectors" target="_blank">mdn docs</a>에서 확인해보자.

선택자 여러개에 한번에 속성을 적용할 수도 있다. 이는 콤마(`,`)를 사용한다.

```css
h1,
h2,
h3 {
  color: red;
}
```

## 스타일 속성

- `padding` - 테두리와 내용 사이의 여백(안쪽 여백)
- `margin` - 테두리와 다른 요소 사이의 여백(바깥쪽 여백)
- `color` - 글자 색상
- `background-color` - 배경 색상
- `font-size` - 글자 크기
- `font-weight` - 글자 굵기
- `text-align` - 글자 정렬
- `display` - 요소 표시 방법
- `position` - 요소 위치 지정
- `float` - 요소 배치 방법
- `z-index` - 요소 순서 지정

## 네스팅

네스팅은 스타일 시트 내부에 스타일 시트를 중첩하는 것이다. 이는 스타일 시트를 더 간결하게 만들어주는 역할을 한다.

```css
div {
  color: red;
  p {
    color: blue;
    span {
      color: green;
      &:hover {
        color: yellow;
      }
    }
  }
}
```
