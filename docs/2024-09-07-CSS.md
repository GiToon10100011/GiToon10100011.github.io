# CSS

> 스타일 시트 언어로, 태그에 스타일을 부여하는 언어이다.

## 스타일 속성

- `padding` - 테두리와 내용 사이의 여백(안쪽 여백)
- `margin` - 테두리와 다른 요소 사이의 여백(바깥쪽 여백)
- `color` - 글자 색상
- `background-color` - 배경 색상
- `font-size` - 글자 크기
- `font-weight` - 글자 굵기
- `text-align` - 글자 정렬
- `display` - 요소 표시 방법
- `position` - 요소 위치 지정
- `float` - 요소 배치 방법
- `z-index` - 요소 순서 지정
