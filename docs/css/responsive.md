# 반응형

## 반응형 스타일 속성

- `@media` - 미디어 쿼리를 사용하여 반응형 디자인을 구현
- `min-width` - 최소 너비를 지정하여 스타일 적용
- `max-width` - 최대 너비를 지정하여 스타일 적용

## 뷰포트 단위

- `vw` - 뷰포트 너비의 1%
- `vh` - 뷰포트 높이의 1%
- `vmin` - 뷰포트 너비와 높이 중 작은 값의 1%
- `vmax` - 뷰포트 너비와 높이 중 큰 값의 1%
