## 컴퓨터 운영체제

컴퓨터는 어느 작업이던지 간에 0, 1로만 처리를 한다. 이를 이진법이라고 한다. (인간은 10진수)

0은 false, 1은 true로 처리한다.

이를 비트라고 한다. 비트가 8개 모이면 바이트가 된다.

바이트는 메모리에 저장되어 있는 데이터를 처리하는 기본 단위이다.

rgb 함수는 16진수로 표현된 색상을 받아서 빨간색, 초록색, 파란색을 반환한다.

`255 255 255` - 흰색
`000 000 000` - 검정색
