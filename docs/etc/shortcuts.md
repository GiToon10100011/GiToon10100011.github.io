# 단축키

> 단축키들을 모아둔 페이지
  
## VSCode

- `alt/option` + `up/down` - 라인 이동

- `alt/option` + `shift` + `up/down` - 라인 복사

- `ctrl/command` + `alt/option` + `up/down` - 라인 다중 선택

- `ctrl/command` + `\` - 탭 쪼개기

- `ctrl/command` + `shift` + `k` - 라인 삭제 (cursor에서는 composer)

- `ctrl/command` + `b` - 사이드바 펼치기/접기

- `ctrl/command` + `shift` + `p` - 명령 팔레트 열기

- `ctrl/command` + `p` - 빠른 열기

- `ctrl/command` + `shift` + `n` - 새 창 열기

- `ctrl/command` + `shift` + `o` - 파일 열기

- `ctrl/command` + `shift` + `u` - 대문자 변환

--- 

## 개발자 도구

- `alt/option` + `click` - 콘솔에서 네스팅된 요소들을 빠르게 펼쳐보는 방법

- `alt/option` + `control` + `click` - 콘솔에서 네스팅된 모든 요소들을 빠르게 펼쳐보는 방법 (렉 주의)
