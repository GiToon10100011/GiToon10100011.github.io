# UI/UX

> UI(User Interface), UX(User Experience)

`UX`는 특정 브랜드를 떠올릴 때 연상되는 디자인/이미지, 즉, 브랜드 아이덴티티를 통해 충성고객(Loyal Customer)을 만드는 것을 목표로 한다. <span style="color: #aaa;">(결국 `UX`가 좋으면 기업의 매출도 좋아진다.)</span>

UI는 웹 사이트의 디자인을 의미하며, 웹 사이트의 디자인을 최적화하여 사용자 경험을 향상시키는 것을 목표로 한다.

현재 가장 많이 사용되는 다양한 레이아웃 및 디자인 패턴을 확인하려면 <a href="https://gs.statcounter.com/screen-resolution-stats">statcounter(통계 사이트)</a>를 활용하는 것이 좋다.

## 폰트

폰트는 웹 사이트의 디자인을 최적화하여 사용자 경험을 향상시키는 것을 목표로 한다.

특정 사이트의 폰트가 궁금하다면 개발자 도구를 열어서 네트워크 탭 중 글꼴/font 탭을 클릭하면 폰트 정보를 확인할 수 있다.

이때, woff라는 확장자로 다운이 된다. 해당 파일은 웹 전용 폰트고 로컬에서 사용하려면 ttf/otf 확장자로 변환할 필요가 있다.

폰트 변환 사이트는 <a href="https://www.fontsquirrel.com/tools/webfont-generator">Font Squirrel Web Font Generator</a>를 활용하는 것이 좋다.

- `ttf` - 폰트를 개발할 때 베지에 곡선을 사용할 수 있는 폰트, Apple+MS가 합작해서 만든 확장자로, 범용적인 문서 및 디자인 작업 시 사용하기 위해 만들었다. 용량이 적고, 2차 베지에 곡선을 사용하는 것이 특징이다. <span style="color: #aaa;">(범용성으로 인해 윈도우에서 많이 쓰이게 됨.)</span>
- `otf` - Adobe+MS에서 만든 폰트 확장자로, 고출력의 디자인 작업시 사용하기 위해 만들어, 용량이 큰것이 특징이다. 3차 베지에 곡선을 사용함. <span style="color: #aaa;">(전문 디자이너들이 많이 사용하여 맥에서 많이 사용됨.)</span> 

## 기획

제품, 서비스 제작 기획 회의를 통해 어떤걸 먼저 만들지 결정한다. 이때, 우리가 만들 제품, 서비스의 목표를 정의하고, 그 목표를 달성하기 위한 방법을 고민한다.

target, segment, persona 등을 정의하고, 이를 바탕으로 제품, 서비스의 목표를 정의한다.

## 웹 표준

웹 표준은 웹 사이트의 디자인을 최적화하여 사용자 경험을 향상시키는 것을 목표로 한다.
