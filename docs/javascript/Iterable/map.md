# Map

> `Map`은 키와 값의 쌍으로 이루어진 자료구조이다. 키와 값은 모두 임의의 타입을 가질 수 있다. `Map`은 `key-value` 쌍으로 이루어진 자료구조이다. 키와 값은 모두 임의의 타입을 가질 수 있다.

```javascript
const map = new Map();
```

자바스크립트에서는 이터러블 객체가 아닌 요소들을 위해 Map이라는 객체를 제공하여 반복을 할 수 있게끔 한다.
