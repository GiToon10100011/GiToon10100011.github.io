# Set

> `Map`과 달리, `Set`은 중복되지 않는 유일한 값들의 집합이다. `Set`은 중복되지 않는 유일한 값들의 집합이다.

```javascript
const set = new Set();
```

`Set`은 `Map`과 달리, 키와 값의 쌍으로 이루어진 자료구조가 아니다. 대신, 값만 저장한다.
