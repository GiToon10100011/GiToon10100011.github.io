# Math

> 수학 관련 함수들을 제공하는 객체

## 자주 사용하는 메소드 & 속성

- `Math.PI` - 원주율
- `Math.floor()` - 소수점 이하를 버림
- `Math.ceil()` - 소수점 이하를 올림
- `Math.round()` - 소수점 이하를 반올림
- `Math.abs()` - 절대값
- `Math.max()` - 최대값
- `Math.min()` - 최소값
- `Math.random()` - 랜덤값
- `Math.sqrt()` - 제곱근
